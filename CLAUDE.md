# Portfolio Kenny Pignolet

## Interface

Avant toute modification visuelle (CSS, composant, nouvelle page), lire
`design-system/kenny-pignolet/MASTER.md`, puis `design-system/kenny-pignolet/pages/<page>.md`
s'il existe (ses règles priment). Mettre ces fichiers à jour quand une règle change.

## Vérifications

Depuis `frontend/` : `npm run check` (lint, types, tests, build, SEO, e2e avec axe).
En local, les e2e peuvent utiliser le Chrome installé : `PLAYWRIGHT_CHROMIUM_PATH`.
